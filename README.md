# Herramientas Básicas UTN - Bustos Ivo Nehuén

## Proyecto final para la aprobación del curso

**Alumno:** Ivo Nehué Bustos

## Objetivo

Encontrar los factores determinantes para poder subir al Monte Everest.

## Fuente de datos

**Kaggle - Everest & the Death Zone — Will They Summit?**

[Dataset en Kaggle](https://www.kaggle.com/datasets/sergionefedov/everest-and-the-death-zone-will-they-summit)

## Pasos del proyecto

1. Preguntas a contestar.
2. Visualización de datos.
3. Definición de preguntas finales.
4. Análisis y limpieza de datos.
5. Respuesta de las preguntas mediante análisis acompañado de sus respectivos gráficos.
6. Conclusión.
